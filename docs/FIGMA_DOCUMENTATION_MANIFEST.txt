🔑 KEY CONCEPTS EXPLAINED

HIERARCHY:
  FILE (Siapin Design System v1)
  └─ PAGE (8 halaman)
     └─ BOARD (organizer, not exported)
        └─ FRAME (container, 1920×1080 atau 375×667)
           └─ ELEMENT (content inside frame)
              ├─ RECTANGLE (color swatches, backgrounds)
              ├─ TEXT (labels, typography)
              ├─ VECTOR/SVG (icons, patterns)
              ├─ IMAGE (screenshots)
              └─ COMPONENT (reusable, synced)


ELEMENT TYPES:
  ✓ RECTANGLE → For colors, backgrounds, shapes
  ✓ TEXT → For labels, headings, body text
  ✓ VECTOR/SVG → For icons, patterns, custom shapes
  ✓ IMAGE → For screenshots, photos
  ✓ COMPONENT → For reusable UI (buttons, cards, etc)
  ✓ GROUP → For organizing (not reusable)
  ✓ FRAME → Container for all content


NAMING FORMULA:
  [Type] / [Component] / [Variant]
  
  Examples:
  ✅ Button / Primary
  ✅ Button / Primary / Hover
  ✅ Card / KPI
  ✅ Icon / Dashboard / 24
  ✅ Color / Blue / Primary
  
  NOT:
  ❌ Button1, Button2
  ❌ Rectangle 1
  ❌ Component copy
