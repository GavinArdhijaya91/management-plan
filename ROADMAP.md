# Siapin Roadmap

The roadmap describes evidence required for the next milestones. It is not a
promise of dates, production availability, or a managed hosted service.

## Now — complete the core evidence loop

- [x] Define a metric and target from the authenticated planning journey.
- [x] Record an actual result with an explicit source.
- [x] Compare compatible target and actual periods.
- [x] Prepare and finalize a review through the canonical RPC.
- [x] Render the immutable evidence snapshot.
- [ ] Cover the happy path and unauthorized path in database and E2E tests.

## Next — validate collaboration and accessibility

- [ ] Complete invitation by link and email from both owner and recipient views.
- [ ] Verify every workspace action against the documented role matrix.
- [x] Add the direct custom-role planning pgTAP scenario tracked in the security matrix.
- [ ] Audit critical journeys against WCAG 2.2 AA-oriented keyboard, focus,
      contrast, zoom, error, and reduced-motion checks.
- [ ] Run moderated onboarding sessions with first-time business planners.
- [ ] Publish known limitations and research findings without private user data.

## Later — staging and sustainability decision

- [ ] Complete every Stage 1 gate in the release and hosting strategy.
- [ ] Run an invited pilot only after privacy, retention, recovery, and incident
      procedures exist.
- [ ] Decide whether Siapin remains self-host-only or gains a managed edition.
- [ ] Define a sustainable operating model before promising broad free hosting.

## Explicitly not promised

- Production readiness or an SLA
- Replacement for accounting, legal, or financial advice
- Universal suitability for every business or user
- Automated AI business decisions
- Unverified “real-time” market truth
