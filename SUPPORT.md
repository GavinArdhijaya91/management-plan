# Support

Need help with Siapin? Here is where to look first.

---

## I just want to run the project

Follow the step-by-step guide in [README.md](./README.md) — section **“Get started — from zero to running”**. It covers everything from installing Node.js to running the database and opening the app.

If you get stuck, check the **Troubleshooting** section at the bottom of the README.

---

## I found a bug

Please open an issue using the **Bug Report** template:

👉 `.github/ISSUE_TEMPLATE/bug-report.yml`

Include:

- What you did (steps)
- What you expected
- What you actually saw
- Your Node.js and pnpm versions (`node -v`, `pnpm -v`)
- Screenshots if helpful (blur any private data)

---

## I have an idea or feature request

Open an issue using the **Scoped Task** template:

👉 `.github/ISSUE_TEMPLATE/scoped-task.yml`

For big ideas, please open an issue **before** writing code so we can discuss scope together.

---

## I have a question (how do I…?)

- Check [docs/README.md](./docs/README.md) — the full documentation index
- Check [Domain Glossary](./docs/DOMAIN_GLOSSARY.md) — what each business word means
- Check [Getting Started](./docs/GETTING_STARTED.md) for project structure
- If still unsure, open a GitHub Issue with the label `question` — there is no silly question

---

## I found a security problem

**Do not** open a public issue.

See [SECURITY.md](./SECURITY.md) and report it privately via:

👉 https://github.com/GavinArdhijaya91/management-plan/security/advisories/new

---

## Response time

Siapin is maintained by a small team, often in spare time. We will do our best to respond within a few days. Thank you for your patience.
